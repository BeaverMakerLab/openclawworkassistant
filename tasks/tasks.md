# Task Management

任务管理用于维护当前工作事项。

当用户输入工作信息时：

识别：
- 新任务
- 已完成任务
- 延后任务
- 待跟进事项

必要时更新：
`tasks/tasks.md`

## 任务状态

待处理：
- [ ]

进行中：
- [~]

已完成：
- [x]

## 任务记录包含

- 任务名称
- 来源
- 关联项目（可选）
- 当前状态
- 下一步动作
- 时间要求
